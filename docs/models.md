## Models

Algorithms in the "models" folder are based on well-known architectures for semantic segmentation, briefly described below with relevant citations and code sources.

* **Tiramisu (100-layer DenseNet-based FCN)**: A fully convolutional DenseNet for semantic segmentation introduced by Jégou et al. [The One Hundred Layers Tiramisu: Fully Convolutional DenseNets for Semantic Segmentation](https://arxiv.org/abs/1611.09326). Implementation adapted from [bfortuner/pytorch\_tiramisu](https://github.com/bfortuner/pytorch_tiramisu), whose repository also provides useful training utilities.

* **Attention U-Net**: An enhanced U-Net incorporating attention gates as proposed by Oktay et al. [Attention U-Net: Learning Where to Look for the Pancreas](https://arxiv.org/abs/1804.03999). Implementation adapted from [BinaLab/RescueNet](https://github.com/BinaLab/RescueNet-A-High-Resolution-Post-Disaster-UAV-Dataset-for-Semantic-Segmentation/tree/main).
