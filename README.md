### Introduction

This repository serves as the foundation for semantic segmentation experiments conducted within the **HaMMon** project. It provides an operational framework for managing training experiments, supporting a structured and reproducible workflow.
For more information on the experimental framework and configuration, see the `/docs` directory.

## Disclaimer

This code is currently being migrated from a private repository and is a work in progress. It requires debugging, cleanup, refinement, and more comprehensive documentation.
