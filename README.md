### Introduction

This repository serves as the foundation for semantic segmentation experiments conducted within the **HaMMon** and **HaMMon-EQ** projects. It provides an operational framework for managing training experiments, supporting a structured and reproducible workflow.
For more information on the experimental framework and configuration, see the `/docs` directory.

## Disclaimer

Recent refactoring has not been thoroughly tested, so expect minor bugs. Internal utilities (e.g., tracking tools, plotting scripts and other minor libraries) are shared for convenience during development and are not hardened for general-purpose use; they may contain defects or missing safeguards.
